## Configuring Snort IPS via Pfsense (WAN Interface)
* Configured Snort Oinkmaster code - Translation; License key for rule updates.
* Emerging Threats Open Rules - Translation; Detects malware, exploits, botnets, suspicious traffic, and other known threats.
* Sourcefire OpenAPPID Detectors Translation; Helps Snort identify applications regardless of port number (e.g., Discord, YouTube, Netflix, BitTorrent).
* APPID Open Rules - Translation; Allows Snort to generate alerts based on specific applications rather than just IP addresses and ports.
* Snort GPLv2 Enabled - Translation; Contains additional detection signatures contributed by the community.
